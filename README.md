# SG Food

A small collection of Singapore food field guides — hand-curated, single-page,
no build step. Each guide is a static HTML page that opens directly in any
browser.

## Guides

- **`index.html`** — *Ten Plates of Nasi Lemak Worth Leaving Home For.*
  A shortlist of Singapore nasi lemak stalls filtered for a Redhill Close
  postcode: ~4.5-star Google rating, breakfast hours where possible, and a
  drive under twenty minutes on a clear morning. Includes filter chips for
  breakfast-open, short-drive, traditional, and modern picks. Every entry
  links to a live Google Maps search so hours and ratings can be verified
  before setting off.

## How to view

Open `index.html` in any modern browser. No dependencies, no build step.

## Notes

Hawker stalls close without notice and Google ratings drift week to week.
Each guide is a snapshot in time — use the "Verify on Maps" links on each
entry to confirm today's hours before travelling.
